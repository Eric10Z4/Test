# C++ 算法练习与解题实现

本仓库保存个人 C++ 算法练习，当前入口是 `repo_test/test.cpp`。
程序按多组整数序列读取输入，通过配对累计与剩余元素比较输出一个整数。原始题目链接和完整约束尚未记录；以下样例用于说明当前程序行为，不作为题意证明。

## 当前练习展示的内容

- **数据组织**：使用 `std::set` 跟踪未配对数值，并利用有序遍历构造候选序列。
- **候选搜索**：通过二分查找确定满足当前比较条件的候选位置，完成结果更新。
- **数值处理**：累计值使用 64 位整数，配对乘法显式提升类型。
- **工程习惯**：使用标准 C++17 头文件，保留可运行样例，提供编译警告检查和 CMake 构建入口。

按当前实现，单个用例的时间复杂度为 O(n log n)，额外空间为 O(n)。这些说明对应已提交代码；题目来源与完整约束仍待补充。

## 构建与运行

需要支持 C++17 的编译器：

```sh
g++ -std=c++17 -O2 -Wall -Wextra repo_test/test.cpp -o test
./test < examples/input.txt
```

也可使用 `cmake -S . -B build`、`cmake --build build`。Windows 可执行文件为 `test.exe`（CMake 多配置构建位于相应配置目录）。

输入首行为用例数 `t`；每组先给元素数 `n`，再给 `n` 个整数。每组输出一行。示例见 `examples/input.txt`、`examples/output.txt`。
