# 算法练习备份

我的写题代码备份仓库，保存 C++、Python 练习、解题笔记和调试草稿，方便查找与回顾。

| 目录 | 内容 |
| --- | --- |
| `solutions/` | Codeforces、洛谷、LeetCode、PAT 题目代码 |
| `python/` | 基础练习、2048 和数据结构实现 |
| `drafts/` | 尝试版本、对拍程序和未整理草稿 |
| `fixtures/` | 题目输入输出样例 |
| `notes/`、`references/` | 解题笔记与题面材料 |
| `extras/` | 随手保存的辅助脚本与笔记 |
| `repo_test/` | 原仓库中的算法练习 |

完整文件列表见 [索引](INDEX.md)。代码包含未完成或未验证的版本，不统一保证通过题目评测。

本仓库作为只读备份归档；需要继续更新时可取消归档。授权与来源见 [AUTHORIZATION.md](AUTHORIZATION.md)。
